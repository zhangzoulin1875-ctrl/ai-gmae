# AI Fallback Chain 設計

管理員後台可設定多個 AI Provider 的優先順序，確保一家斷線遊戲不卡死。

## 降級鏈架構

```
回合結算請求
     │
     ▼
┌─────────────┐  成功  →  使用結果
│ Provider 1  ├──────────▶ Done
│ (最高優先)  │
└──────┬──────┘
       │ 失敗/逾時/限流
       ▼
┌─────────────┐  成功  →  使用結果
│ Provider 2  ├──────────▶ Done
│ (降級)      │
└──────┬──────┘
       │ 失敗/逾時/限流
       ▼
┌─────────────┐  成功  →  使用結果
│ Provider 3  ├──────────▶ Done
│ (最後手段)  │
└──────┬──────┘
       │ 全部失敗
       ▼
┌─────────────────────────┐
│ Fallback: 確定性結算     │
│ (不依賴 LLM 的規則結算)  │
└─────────────────────────┘
```

## 管理員設定介面

每個 Provider slot 可設定：
- **類型**: openai_compatible | google | custom
- **名稱**: 自訂標籤（方便識別）
- **API Key**: 加密儲存
- **Base URL**: API endpoint
- **Model**: 模型名稱
- **權重/順序**: 拖曳排序
- **逾時**: 超時秒數（預設 30s）
- **重試次數**: 失敗前重試幾次（預設 2）
- **狀態指示**: ●正常 / ●限流 / ●斷線

## 回合時程

台灣時間 (UTC+8)：
- **活躍時段**: 08:00 - 24:00（每天 8 回合）
- **休眠時段**: 00:00 - 08:00（不結算，玩家仍可下指令）
- **回合時間**: 每整點的偶數小時結算（08:00, 10:00, 12:00, 14:00, 16:00, 18:00, 20:00, 22:00）
- **每回合時長**: 2 小時

```
08:00 ──回合1──▶ 10:00 ──回合2──▶ 12:00 ──回合3──▶ 14:00
  │                                               │
14:00 ──回合4──▶ 16:00 ──回合5──▶ 18:00 ──回合6──▶ 20:00
  │                                               │
20:00 ──回合7──▶ 22:00 ──回合8──▶ 00:00
  │
00:00 ── 休眠（不結算）──▶ 08:00 ──回合1──▶ ...
```
